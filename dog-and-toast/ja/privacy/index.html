プライバシーポリシー

DOG & TOAST の端末内データ、サポートメール、このサイトについて。

更新日 2026-10-22 · Crumb Lantern

制作元

DOG & TOAST は Crumb Lantern の作品です。ゲーム内の開発者表記は jianchenliu です。本方針は現在のゲーム、ヘルプページ、任意のサポート依頼に適用されます。

進行状況は端末に保存

現在のステージ、旗、集めた骨、仕掛けの進行、自己ベスト、言語、音量、振動、操作配置を端末内に保存します。プレイヤーアカウントは不要です。

広告・追跡サービスなし

現在のゲームには広告、アプリ内課金、解析 SDK を組み込んでいません。進行状況のアップロード、広告用プロファイルの作成、独自の端末間クラウド同期は行いません。

権限と吠えるボタン

ゲームのコードはカメラ、マイク、位置情報、連絡先、写真へのアクセスを要求しません。吠える操作は効果音を再生するゲーム動作で、声を録音しません。

エンジン、Apple、バックアップ

Unity を使用しています。ストアのダウンロード、支払い、任意のシステム診断は Apple の方針で処理されます。OS のバックアップにアプリのローカルデータが含まれる場合がありますが、端末間の復元は保証しません。

端末内の開発ログ

開発・テスト版では端末、OS、動作性能、ゲームイベントのログを端末内に記録することがあります。スタジオへの自動送信、サポート添付、クラッシュ報告の自動アップロード機能はありません。

ウェブページを開くとき

公開ページは GitHub Pages を使用します。GitHub は安全対策のため、未ログイン時も訪問者の IP アドレスを記録・保存し、同社のプライバシー声明に従って扱います。このページ独自の広告、解析、Cookie、ブラウザーへの保存はありません。メールにはメール事業者が関わります。セーブやログは自動添付しません。

GitHub · プライバシーポリシー

自分で送信するメール

お問い合わせでは、送信したメールアドレス、本文、選んだ添付ファイルを受け取ります。調査と返信に利用します。問い合わせ先は Gmail（Google）を利用しています。Gmail と送信元のメール事業者は、それぞれの方針に従ってメールを処理します。

保存期間と削除

お問い合わせの記録は対応と適用される義務に必要な期間のみ保持します。開示・削除はメールでご相談ください。アプリ削除で進行状況を失う場合があり、OS のバックアップは別途管理してください。ローカル設定は機密情報用の暗号化保管庫ではありません。

年少のプレイヤー

プレイ中に氏名、年齢、連絡先を求めません。不要な個人情報を送らないでください。子どもが個人情報を送った場合、保護者はメールで削除を依頼できます。

更新とお問い合わせ

ゲームやサポートの情報処理方法が変わる場合、この方針を更新します。上記の日付が版を示します。プライバシーに関するご相談は jianchen120695@gmail.com へ。
