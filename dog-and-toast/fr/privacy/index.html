Politique de confidentialité

Les sauvegardes locales, les e-mails et ces pages pour DOG & TOAST.

Mise à jour 2026-10-24 · Crumb Lantern

Qui crée le jeu

DOG & TOAST est créé par Crumb Lantern. Le développeur crédité dans le jeu est jianchenliu. Cette politique couvre le jeu actuel, ces pages et les demandes volontaires au support.

La progression reste sur l’appareil

Le jeu enregistre localement le niveau, le drapeau, les os collectés, les mécanismes, les meilleurs résultats, la langue, le son, les vibrations et la disposition des commandes. Aucun compte joueur n’est nécessaire.

Sans service publicitaire ou de suivi

Le jeu ne contient aucun SDK publicitaire ou d’analyse. Son code ne transmet pas votre progression, ne crée pas de profil publicitaire et ne fournit pas de synchronisation cloud propre au studio.

Autorisations et aboiement

Le code du jeu ne demande pas l’accès à la caméra, au microphone, à la localisation, aux contacts ou aux photos. Aboyer est une action sonore du jeu ; votre voix n’est pas enregistrée.

Moteur, Apple et sauvegardes système

Le jeu utilise Unity. Apple traite les téléchargements, paiements et diagnostics système facultatifs selon ses propres règles. Les sauvegardes système peuvent inclure les données locales ; la récupération sur un autre appareil n’est pas garantie.

Informations d’achat Apple

Apple traite l’achat unique facultatif de la version complète. StoreKit fournit l’état d’achat vérifié et le prix local. Le studio ne reçoit ni vos données bancaires ni votre mot de passe App Store. Restaurer un achat rétablit l’accès, pas les sauvegardes locales.

Diagnostics locaux de développement

Les versions de développement ou de test peuvent écrire des journaux locaux sur l’appareil, le système, les performances et les événements du jeu. Ils ne sont pas envoyés automatiquement au studio. Le jeu actuel n’envoie automatiquement ni pièces jointes ni rapports de plantage.

Lorsque vous ouvrez un site

Ces pages utilisent GitHub Pages. GitHub enregistre et conserve les adresses IP pour la sécurité, même sans connexion, selon sa déclaration de confidentialité. Nos pages n’ajoutent ni publicité, ni analyse, ni cookies, ni stockage navigateur. Votre fournisseur traite les e-mails ; aucune sauvegarde ni aucun journal n’est joint automatiquement.

Les messages que vous envoyez

Si vous nous écrivez, nous recevons votre adresse e-mail, votre message et les pièces jointes choisies. Nous les utilisons pour enquêter et répondre. La boîte de support utilise Gmail (Google). Gmail et votre fournisseur de messagerie traitent les messages selon leurs propres règles.

Conservation et suppression

Les échanges sont conservés seulement selon les besoins de la demande et les obligations applicables. Contactez-nous pour un accès ou une suppression. Désinstaller peut effacer la progression locale ; gérez séparément les sauvegardes système. Les réglages locaux ne sont pas un coffre chiffré pour données sensibles.

Jeunes joueurs

Le jeu ne demande ni nom, ni âge, ni coordonnées pendant la partie. Évitez les données personnelles inutiles. Si un enfant en a envoyé, un parent ou responsable peut en demander la suppression par e-mail.

Modifications et contact

Nous mettons cette politique à jour si les pratiques du jeu ou du support changent. La date en haut identifie la version. Pour toute question de confidentialité : jianchen120695@gmail.com.
